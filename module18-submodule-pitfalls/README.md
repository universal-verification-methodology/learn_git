**Kind:** `lab` · Primary lab: `submodule-pitfalls` · **Shipped**

## Outcomes

After this module you can explain and practice the ideas taught by **`submodule-pitfalls`**, in the browser and/or with real Git.

## Two tracks (pick one or both)

### Track A — Real Git (hands-on)

Work in a local practice repo using this module’s `examples/` (adapted from `learn_unix_git`).

1. Open [EXAMPLES.md](EXAMPLES.md) and run the “Try these” commands.
2. Complete [CHECKLIST.md](CHECKLIST.md) in `~/unix_practice/git_demo` (or your sandbox clone).
3. Optional self-check: `./scripts/module.sh 18 --check` (from course root).

### Track B — Browser lab (online)

1. Local: [http://127.0.0.1:8080/tools/submodule-pitfalls/index.html](http://127.0.0.1:8080/tools/submodule-pitfalls/index.html)
2. Live: [https://universal-verification-methodology.github.io/learning/tools/submodule-pitfalls/](https://universal-verification-methodology.github.io/learning/tools/submodule-pitfalls/)
3. Load the **starter example**, then work challenges.
4. Check off the Track B items in [CHECKLIST.md](CHECKLIST.md).

> Concept labs are literacy tools — they do not replace real Git for remotes, PRs, and submissions.
