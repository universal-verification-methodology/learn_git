## Slide 1 — Git path complete

You have walked the Git path for coursework—from the mental model of working tree, index, and commits, through branches, merges, and recovery, to remotes, pull requests, submodules, and a live sandbox rehearsal. This short wrap names what you can do now and points you to the next courses on the ladder.

## Slide 2 — What you can do now

You can explain how files move from working tree to index to commit graph. You can stage, commit, read history, and undo safely. You can branch, merge or rebase, and recover with reflog when something goes wrong. You can use remotes and pull-request basics, handle submodule pitfalls when shared IP appears, bootstrap from a template, and rehearse a reproducible submission. That is the Git literacy every later design course expects.

## Slide 3 — Close the track gaps

If you mainly used browser labs, spend a short real-Git session on commits, conflicts, remotes, and the sandbox so push and pull feel natural—not only the concept quizzes. If you mainly used a real terminal, skim any skipped browser labs for the visual challenges on the graph, conflicts, and remote-tracking. Either track works for self-study; both together stick best before you move on.
